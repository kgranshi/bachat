# समूह बचत एप — स्थिति (इमानदार)

## फाइल संरचना (अब छुट्टै)
- index.html          → UI मात्र + script लिंक
- css/styles.css
- js/db.js            → localStorage + Firestore
- js/accounting.js    → हिसाब सूत्र (यो नछोइने)
- js/auth.js          → लगइन
- js/ui.js            → UI helpers, BS मिति
- js/app.js           → स्क्रिन / कलेक्सन / च्याट / बिल
- sw.js, manifest.json, icon-*.png
- firebase-config.js  → Netlify मा आफ्नो config राख्ने
- firebase-messaging-sw.js

## काम भएको (कोडमा छ)
1. Admin / सदस्य लगइन, PIN, कलेक्सन, ऋण, महिना बन्द
2. अकाउन्टिङ सूत्र (सुरु/आम्दानी/खर्च/मौज्दात/ऋण/नगद)
3. अग्रिम / बाँकी / जरिवाना logic
4. समूह + व्यक्तिगत च्याट
5. महिना बन्द → डिजिटल रसिद (प्राइभेट) + बिल नं 2083/84/01…
6. कलेक्सन सारांशमा बिल हेर्ने बटन
7. महिना बन्द → JSON ब्याकअप डाउनलोड
8. दोस्रो शुक्रबार ६ बजेपछि एप खुले → प्राइभेट रिमाइन्डर (एप खुला चाहिन्छ)
9. PWA: manifest लिंक, PNG आइकन, service worker
10. थिम/लोगो फोटो, सदस्य फोटो/ठेगाना (सेटिङ/प्रोफाइल)
11. Firebase क्लाउड सिंक (config.js + लगइन)

## अधुरो / सीमा (ढाट्दैन)
1. एप बन्द हुँदा तोकिएको सेकेन्डमै रिमाइन्डर — वेबले सक्दैन (सर्भर/Script चाहिन्छ)
2. Google Drive मा सिधै अटो अपलोड — OAuth/Script बिना हुँदैन; अहिले डाउनलोड मात्र
3. Push notification — अनुमति + FCM; बन्द एपमा सीमित
4. फिंगरप्रिन्ट — सबै फोन/Chrome मा नचल्न सक्छ
5. Multi-group (धेरै Admin/समुह) — बनेको छैन
6. Apps Script बाट सिधै Firebase च्याट लेख्ने — सुरक्षित सरल तरिका छैन

## तपाईंले खोजेको मुख्य लक्ष्य
- गाउँ बचत हिसाब एप, मोबाइल, लिंक+पासवर्ड, अफलाइन+सिंक
- कलेक्सन/ऋण/महिना, सदस्य पासबुक, च्याट, बिल/रसिद
- दोस्रो शुक्रबार रिमाइन्डर, महिना बन्दमा ब्याकअप

## बाँकी व्यावहारिक काम (प्राथमिकता)
A) Netlify मा यो छुट्टै-फाइल ZIP + आफ्नो firebase-config.js एक पटक सही deploy
B) वास्तविक फोनमा: महिना बन्द → बिल आउँछ कि, ब्याकअप डाउनलोड हुन्छ कि परीक्षण
C) रिमाइन्डर: दोस्रो शुक्रबार ६ बजेपछि Admin एप खोलेर जाँच
D) Drive: डाउनलोड भएको JSON लाई Drive फोल्डरमा सेभ गर्ने बानी/प्रक्रिया
E) चाहियो भने मात्र: multi-group वा सर्भर रिमाइन्डर (नयाँ काम)
